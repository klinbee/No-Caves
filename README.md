# No Caves
Don't want caves? You're in luck! This datapack removes them. There are still underground features and structures (Ancient Cities, Strongholds, Mineshafts, Amethyst Geodes, Lava Pools, Ores, etc.) but no more caves.

Removed are caves in the overworld and the nether and for the amplified and large biomes world presets too.

There are three editions that each remove different types of caves.

![image](https://github.com/Quidvio/No-Caves-Datapack/assets/105707614/07845624-249c-43bd-b9f1-5ab992c436d1)  


## Packs

- **No Caves**: Removes all caves
- **No Old Caves**: Removes all but only carver caves, leaving the 1.18+ caves
- **No New Caves**: Removes all but only noise caves, leaving the pre-1.18 caves

## Compatability

All No Caves versions are backwards compatible, meaning that the newest version can also be used for the first game version that was compatible (1.20) and all in between.

With other datapacks and mods, compatibility depends on how the mod handles their caves. Such that use vanilla's carver caves or noise cave definitions will be compatible automatically.

Further support is provided for:
- [Tectonic](https://modrinth.com/datapack/tectonic)
- [Flat Dimensions](https://modrinth.com/datapack/flat-dimensions)
- [Overworldify](https://modrinth.com/datapack/overworldify)
